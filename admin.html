Website Mein Changes Kaise Karein

Koi bhi text, image, ya content change karne ka tarika

Option 1: Quick Method (Antigravity/AI se)

Sabse easy: Mujhe (Antigravity) bol dein kya change karna hai — main 2 minute mein update karke live push kar dunga!

Option 2: Khud Manually Edit Karein

  1. File kholein
    D:\mtech-ai-website\ mein jo file edit karni hai use kholein (Notepad, VS Code, ya koi bhi editor)
  2. Changes karein
    Text change karein, image path update karein, ya naya content add karein. Save karein.
  3. Terminal/PowerShell kholein
    Windows key dabayein → "PowerShell" type karein → Open karein
  4. Ye 3 commands chalayein:
    cd D:\mtech-ai-website git add -A git commit -m "description of your change" git push origin master
  5. 2-3 minute wait karein
    GitHub Pages automatically deploy karega. Website refresh karein!

Option 3: GitHub.com Se Directly Edit

  1. GitHub repo kholein:
    github.com/MuneerHussain01/mtech-ai-website
  2. Jo file edit karni hai us pe click karein
    e.g., index.html, about.html
  3. Pencil icon (✏️) click karein
    File editor khul jayega browser mein
  4. Changes karein → "Commit changes" click karein
    2-3 minute mein live ho jayega!

Contact Form — Kaise Kaam Karta Hai

Client jab form submit karta hai to kya hota hai

  1. Client contact.html pe form bharta hai (name, email, project type, message)
  2. Form FormSubmit.co ko POST hota hai
  3. mtechai.solutions@gmail.com pe email aata hai sab details ke saath
  4. Client ko Thanks page dikhai deta hai
First Time Setup: Pehli baar jab koi form submit karega, FormSubmit.co aapko ek verification email bhejega mtechai.solutions@gmail.com pe. Us email mein "Confirm" link click karein. Uske baad sab emails automatically ayengi!
Test Karein: Abhi website pe jayein, contact form bharein aur submit karein. Gmail check karein — FormSubmit se verification email ayega. Confirm karein, phir sab kaam karega!
